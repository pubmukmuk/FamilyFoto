# EXIF-TAGS.md (Compact Reference)

## Date & Time
- `DateTimeOriginal`: Photo taken
- `DateTimeDigitized`: Digitized time
- `DateTime`: File modified time
- `SubSecTimeOriginal`, `SubSecTimeDigitized`: Sub-seconds

## Camera Info
- `Make`, `Model`, `LensModel`, `Software`
- `ExposureTime`, `FNumber`, `ISOSpeedRatings`, `Flash`
- `FocalLength`, `MeteringMode`, `WhiteBalance`
- `ExposureProgram`, `ExposureBiasValue`, `MaxApertureValue`
- `ShutterSpeedValue`, `LightSource`

## GPS Info
- `GPSLatitude`, `GPSLatitudeRef`, `GPSLongitude`, `GPSLongitudeRef`
- `GPSAltitude`, `GPSAltitudeRef`
- `GPSTimeStamp`, `GPSDateStamp`, `GPSProcessingMethod`

## Image Attributes
- `Orientation`, `ImageWidth`, `ImageHeight`, `ColorSpace`
- `ResolutionUnit`, `XResolution`, `YResolution`
- `Compression`, `PhotometricInterpretation`

## Vendor/Advanced
- `ImageUniqueID`, `SerialNumber`, `LensSerialNumber`
- `MakerNote`, `SubjectArea`, `SceneType`
- `CustomRendered`, `ComponentsConfiguration`
